## 🎨 TIER 2: DESIGN & FORMATTING

### **3. Template-Based vs LLM-Direct Generation**

| Approach | Pros | Cons | Best For |
|----------|------|------|----------|
| **Template (Jinja2, Handlebars)** | ✅ Consistent<br>✅ Fast<br>✅ Predictable | ❌ Less flexible<br>❌ Requires templates | Structured reports |
| **LLM Direct Generation** | ✅ Flexible<br>✅ Creative<br>✅ Adaptive | ❌ Variable quality<br>❌ Slower | Narrative reports |
| **Hybrid (Best!)** | ✅ Consistent + Flexible<br>✅ Best of both | ❌ More complex | Production systems |

**Recommendation:** 🔥 **Hybrid Approach**

```python
# Template for structure + LLM for content

# Step 1: LLM generates structured data
data = await llm.extract_from_pdf(pdf)

# Step 2: Template renders HTML with data
html = template.render(data=data, custom_css=modern_styles)

# Step 3: LLM adds narrative insights (optional)
insights = await llm.generate_insights(data)
html += insights_section(insights)
```

## 🔥 TIER 3: LLM-SPECIFIC TECHNIQUES

### **7. Prompt Engineering for HTML Generation** 💡

**BAD PROMPT:** ❌
```
Generate an HTML report for this drilling data.
```

**GOOD PROMPT:** ✅
```
Generate a professional HTML report with the following requirements:

STRUCTURE:
- Use HTML5 semantic elements (<header>, <main>, <section>, <footer>)
- Include a Table of Contents with anchor links
- Organize into 4 sections: Summary, Activities, Costs, Recommendations

STYLING:
- Inline CSS in <style> tag (no external files)
- Modern color scheme: Primary #2c3e50, Secondary #3498db
- Responsive design (mobile-friendly)
- Professional font: Segoe UI
- Card-based layout with subtle shadows

CONTENT:
- Bilingual (Spanish original + English translation)
- All 24 hourly activities in a table
- Cost metrics with trend indicators
- SVG bar chart for daily costs
- Summary statistics with badges

DATA VISUALIZATION:
- Use SVG for charts (no external libraries)
- Color code: Green (on-budget), Yellow (warning), Red (over-budget)
- Include data labels on charts

QUALITY:
- Validate all HTML
- Ensure accessibility (alt text, aria labels)
- Add metadata (author, date, keywords)
```

### **8. Structured Output Format** 📋

**Best Practice:** Ask LLM to return structured data FIRST, then generate HTML

**Two-Step Approach:**

```python
# Step 1: Extract structured data
extraction_prompt = """
Extract from this PDF and return JSON:
{
    "metadata": {...},
    "hourly_activities": [...],
    "costs": {...},
    "summary_metrics": {...}
}
"""

data = await llm.extract(pdf, extraction_prompt)

# Step 2: Generate HTML from structured data
html_prompt = f"""
Generate a professional HTML report from this data:
{json.dumps(data, indent=2)}

Requirements:
- Modern styling with inline CSS
- Responsive design
- SVG charts for cost trends
- Bilingual content (Spanish + English)
"""

html = await llm.generate_html(data, html_prompt)
```

**Why This Works:**
- ✅ Separates data extraction from presentation
- ✅ Easier to validate data before rendering
- ✅ Can reuse data for multiple report formats
- ✅ Better error handling

### **9. Iterative Refinement with Feedback Loops** 🔄

**Best Practice:** Multi-pass generation

```python
# Pass 1: Generate initial HTML
html_v1 = await llm.generate_html(data)

# Pass 2: Validate and critique
critique = await llm.critique(html_v1, criteria=[
    "Is CSS modern and professional?",
    "Are all data points included?",
    "Is the layout responsive?",
    "Are charts clear and labeled?"
])

# Pass 3: Refine based on feedback
html_v2 = await llm.refine_html(html_v1, critique)

# Pass 4: Human review (optional)
if human_review_enabled:
    feedback = get_human_feedback(html_v2)
    html_final = await llm.apply_feedback(html_v2, feedback)
```

### **11. Error Handling & Fallbacks** 🚨

**Robust Generation:**

```python
async def generate_html_report(data, max_attempts=3):
    """Generate HTML with retries and fallbacks"""
    
    for attempt in range(max_attempts):
        try:
            # Attempt LLM generation
            html = await llm.generate_html(data, html_prompt)
            
            # Validate HTML
            if validate_html(html):
                # Extract and validate data completeness
                if verify_data_completeness(html, data):
                    return html
                else:
                    logger.warning(f"Attempt {attempt+1}: Data incomplete")
            else:
                logger.warning(f"Attempt {attempt+1}: Invalid HTML")
        
        except Exception as e:
            logger.error(f"Attempt {attempt+1} failed: {e}")
    
    # Fallback: Use basic template
    logger.warning("LLM generation failed, using fallback template")
    return generate_template_fallback(data)
```

### **12. Hybrid Approach (Template + LLM)** 🔥 RECOMMENDED

**Best of Both Worlds:**

```python
from jinja2 import Template

# Base template (consistent structure)
template = Template("""
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>{{ title }}</title>
    <style>
        {{ css_styles }}
    </style>
</head>
<body>
    <div class="container">
        <header>
            <h1>{{ title }}</h1>
            {{ nav_section }}
        </header>
        
        <main>
            <!-- Summary (LLM-generated) -->
            <section id="summary">
                {{ llm_generated_summary }}
            </section>
            
            <!-- Activities (Template-based) -->
            <section id="activities">
                <h2>Hourly Activities</h2>
                <table>
                    <thead>
                        <tr>
                            <th>Hour</th>
                            <th>Activity</th>
                            <th>Duration</th>
                        </tr>
                    </thead>
                    <tbody>
                        {% for activity in hourly_activities %}
                        <tr>
                            <td>{{ activity.hour }}</td>
                            <td>{{ activity.activity }}</td>
                            <td>{{ activity.duration }}h</td>
                        </tr>
                        {% endfor %}
                    </tbody>
                </table>
            </section>
            
            <!-- Charts (LLM-generated SVG) -->
            <section id="charts">
                {{ llm_generated_charts }}
            </section>
            
            <!-- Insights (LLM-generated) -->
            <section id="insights">
                {{ llm_generated_insights }}
            </section>
        </main>
        
        <footer>
            <p>Generated {{ generation_date }}</p>
        </footer>
    </div>
</body>
</html>
""")

# Hybrid generation
async def generate_hybrid_report(data):
    # LLM generates narrative sections
    summary = await llm.generate_summary(data)
    charts = await llm.generate_svg_charts(data)
    insights = await llm.generate_insights(data)
    
    # Template renders structure
    html = template.render(
        title=data['title'],
        css_styles=MODERN_CSS,
        nav_section=generate_nav(data),
        llm_generated_summary=summary,
        hourly_activities=data['hourly_activities'],
        llm_generated_charts=charts,
        llm_generated_insights=insights,
        generation_date=datetime.now().strftime("%Y-%m-%d %H:%M")
    )
    
    return html
```

**Benefits:**
- ✅ Template ensures consistency
- ✅ LLM adds intelligence and insights
- ✅ Fast and reliable
- ✅ Easy to maintain
